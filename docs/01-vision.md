# Visão do Produto

## Propósito

O WatchTower é uma aplicação para gerenciamento de filmes e séries construída utilizando Flutter.

O projeto foi criado para resolver dois problemas:

1. Organizar uma biblioteca pessoal de conteúdo audiovisual.
2. Servir como um projeto de referência em arquitetura de software.

---

# Objetivos Funcionais

Permitir ao usuário:

* cadastrar filmes;
* cadastrar séries;
* acompanhar o progresso;
* manter histórico;
* pesquisar rapidamente;
* sincronizar entre dispositivos.

---

# Objetivos Técnicos

O projeto será utilizado para estudo de:

* Flutter
* DDD
* Clean Architecture
* Offline First
* Persistência Local
* Sincronização
* APIs REST
* Testes

---

# Público-alvo

Inicialmente o próprio autor.

Posteriormente qualquer desenvolvedor interessado em arquitetura Flutter.

---

# Plataformas

* Android
* Linux
* Web

---

# Visão de Longo Prazo

O WatchTower deverá tornar-se um projeto de referência em Flutter para arquiteturas Offline First.

Toda decisão técnica será documentada através de ADRs e toda evolução significativa será precedida por RFCs.
